# Touring with Tiffany

A WIY concept website for a boutique travel-planning/touring agency that can create trips anywhere in the world.

## Concept
The business is intentionally presented as a personalized travel-planning service rather than a generic travel booking site.

Core flow:
Dream → Design → Book → Go

## Files
- `index.html`
- `style.css`
- `script.js`

## Prototype notes
The destination imagery currently uses remote Unsplash image URLs so the sketch can look complete without creating a large local image library.

The trip inquiry form is front-end only. No inquiry is transmitted yet.

## Future production possibilities
